# HuVa Cohort 01 Joiner Card

A single-page generator for HuVa Academy Cohort 01 members to create their own brand-aligned shareable card and post it to social.

**Live:** https://nickbrutyan-folder.github.io/huva-joiner-card/

## Features

- 4 brand color themes (Yellow / Blue / Black / Cream)
- 6 message presets — 3 Armenian + 3 English
- 2 formats: Square 1:1 (1080×1080) and Story 9:16 (1080×1920)
- Live preview as you edit (name, avatar)
- One-click PNG download or copy-to-clipboard
- QR code on the card → huva.io/academy

## Tech

Single static HTML file. No build, no deps beyond CDN scripts (`html2canvas`, `qrcode-generator`). Works offline once loaded.
